# eRSHU

### About
This application was created specifically for students of Rivne State Humanitarian University (RSHU) to ensure maximum convenience and efficiency in organizing the educational process.

However, Google permanently banned my eRSHU App because of its name and logo. I didn’t give up and reworked it with a new design and branding. Meet [Napoleon](https://github.com/therxmv/Napoleons-Schedule/tree/main).
